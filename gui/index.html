Pick the framework/task rows and the experiment columns you want, then generate a runnable replacement for experiments.sh. Every command is derived from fixed configuration (no free-text input) and follows the argument conventions of the checked-in experiments.sh.

Legend

    Click a column title checkbox to toggle every enabled cell in that column; click a row label to toggle every enabled cell in that row. Grey hatched cells are not applicable and cannot be selected.

    Generated scripts use ./run.sh from the repository root and are not executable by default: run chmod +x experiments.sh afterwards.
